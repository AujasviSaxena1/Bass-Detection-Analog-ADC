# Bass-Detection-Analog-ADC
This project is about designing a mixed signal bass level detection system using LTSpice. An active low-pass filter is used to obtain low-frequency signals, which are then converted to a DC level using an envelope detector, followed by a comparator-based ADC.

# Features

- Active low-pass filter for bass extraction (below 150 Hz)
- Envelope detector for amplitude or level detection
- Comparator-based analog-to-digital conversion for digital threshold detection
- Transient analysis for characterizing the time-domain signal behavior
